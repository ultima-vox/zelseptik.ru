# Project instructions

## General

- Company name is always "ЗЕЛСЕПТИК"
- Use semantic HTML5
- Mobile First
- Do not use Bootstrap
- Do not use Tailwind

## CSS

- Reuse existing classes whenever possible.
- Do not rename existing classes.
- Do not modify core/*.css unless explicitly requested.
- New styles belong in custom.css.

## Components

- Prefer existing components.
- Don't invent new abstractions if an existing one fits.

## Code style

- Vanilla JavaScript only.
- ES2022.
- Accessibility is mandatory.
