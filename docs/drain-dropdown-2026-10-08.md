# Компактный фильтр типа сброса — 8 октября 2026

В боковой панели каталога септиков убрана группа SEO-ссылок «Тип сброса». Существующие SEO-страницы не удалялись. Радиокнопки фильтра заменены одним выпадающим списком «Любой / Самотечный / Принудительный» в существующей дизайн-системе.

Список использует существующие скрытые поля property_3 и property_2. Обработчик initExclusiveFilters синхронизирует их с выбором: включается только одно поле либо оба отключаются для «Любой». Форма остаётся GET, фильтрацию выполняет HostCMS. Серверные обработчики и свойства магазина не менялись. Быстрый фильтр перестраивать повторно не требуется.

На компьютере от 1200 px высота боковой панели ограничена доступной высотой экрана с учётом шапки и отступов; при необходимости прокручивается сама панель. На меньшей ширине панель остаётся в обычном потоке.

Проверки: tests/test-drain-select.cjs проверяет выбор обоих типов, отсутствие ограничений и восстановление параметра из URL; tests/test-native-catalog-filter.py проверяет единственный список и сохранение штатных полей. Существующие проверки отправки заявок и SEO-рендеринга прошли.

Исходные XSL, CSS и актуальный JS с dev сохранены в docs/archive/drain-select-before-2026-10-08/.

Браузерная проверка: выбор принудительного типа передаёт только property_2=1, найдено 68 моделей; самотечного — только property_3=1, найдено 129 моделей. На первых страницах все видимые карточки соответствуют выбранному типу. «Любой» не передаёт ни одно из двух свойств, найдено 196 моделей; выбор сохраняется в списке.

При высоте экрана 936 px панель имеет высоту 792 px и в закреплённом положении занимает область от 120 до 912 px. Внутренняя прокрутка доступна, список открывается вверх, горизонтального переполнения нет.
