# Styled select menus and service hero

Existing single-value selects receive a progressive JS/CSS enhancement in the existing dropdown module. Original fields, names, values and change handlers remain in place. Without JS native controls remain usable. Multiple and listbox selects are not enhanced.

Popup uses design-system color, spacing, radius and shadow tokens. Supports pointer selection, arrow keys, Home/End, Enter/Space, Escape, Tab, typing to find an option, outside-click dismissal and form reset. Disabled/hidden service choices are respected; modal changes resynchronize the control. Text is inserted via textContent. No form submissions are made during verification.

Existing Shop 6 hero now describes service areas rather than equipment models: area count, service and estimate labels, service description and consultation button. Equipment hero copy is unchanged. No new CMS entities or API calls.
