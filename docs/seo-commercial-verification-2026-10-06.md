# Проверка коммерческих URL на dev — 6 октября 2026

Проверены HTTP-переходы, конечный адрес, метатеги и текст основного содержимого 16 URL (9 пар). Ответы с автоматическим следованием редиректам нельзя считать отдельными страницами-дублями: в предыдущем аудите это завысило число проблем.

## Уже настроенные редиректы

Все переходы ниже — один 301, затем 200; получены на dev, проверка продакшена в этом этапе не проводилась.

Не менять SEO-поля исходного `/services/montazh-septikov/` по прежнему предложению: браузер и робот получают страницу ТОПАС после 301. Если нужен отдельный общий лендинг монтажа, потребуется отдельное решение о содержимом и существующем редиректе; автоматически его не снимать.

## Подтверждённый дубль метатегов

`/septiki/` и `/septiki/price/`: оба исходных URL отвечают 200 без редиректов, canonical у каждой страницы указывает на собственный путь основного домена. H1 различаются; у прайс-листа — «Прайс-лист септиков». Содержимое различается, а title и description совпадают. Прайс-лист сохраняет отдельное назначение, универсальный редирект на каталог не требуется.

Предлагаемые SEO-поля прайс-листа:

- Title: `Цены на септики — прайс-лист в Зеленограде и МО | ЗЕЛСЕПТИК`.
- Description: `Прайс-лист септиков для дома и дачи: сравните модели и цены. Доставка и монтаж в Зеленограде и Московской области. Уточните стоимость выбранной комплектации.`

Поля ещё не сохранены в CMS. Не добавлять цены в метатеги без привязки к действующим данным магазина.

## Главная: только черновик

Штатная форма SEO узла структуры ID 1 открыта, исходные значения записаны в `seo-cms-changes-2026-10-06.json`. В форме внесены новые title и description; HostCMS показал сохранённый черновик. Окончательное сохранение не подтверждено: интерфейс остался с индикатором ожидания, браузер сообщил ограничение наблюдения документа с учётными данными. Главная и запрос с дополнительным параметром вернули прежние title и description. Это не завершённое изменение публичной страницы.

После восстановления работы админки:

1. Окончательно сохранить главную через существующую вкладку SEO и подтвердить значения в ответе сайта.
2. Сохранить отдельные метатеги прайс-листа в существующем узле структуры, предварительно прочитав текущие значения.
3. Обновить SEO элемента ТОПАС в существующей информационной системе; ID из старого SQL-бекапа использовать только после подтверждения в актуальной CMS.
4. Перепроверить sitemap на наличие исходных 301-адресов, а также ранее найденных 404/410. Исключать их через штатные настройки и существующие сущности.
