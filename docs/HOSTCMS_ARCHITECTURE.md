# HostCMS: подтверждённый снимок и пробелы аудита

Статус: **предварительный аудит репозитория и снимка системных характеристик**. Основание — ветка `codex/hostcms-baseline-homepage`, её [`README.md`](../README.md), [`hostcmsfiles/README.md`](../hostcmsfiles/README.md), [`hostcms-deployment.md`](hostcms-deployment.md), список файлов GitHub и предоставленный пользователем скриншот от 28.09.2026. Пользователь сообщил, что файлы с dev уже перенесены на production. Серверная сверка в этой работе не проводилась; скриншот не указывает, к какому именно окружению относятся показанные версии.

## Подтверждено файлами Git

- В репозитории лежат `templates/template1/template.htm`, `templates/template2/template.htm`, `templates/template1/script.js` и корневой `script.js`.
- В `hostcmsfiles/xsl/` лежат файлы с ID `2, 6, 55, 56, 176, 180, 224, 230, 247, 271, 272, 278, 281, 282, 283, 284, 285, 286, 288`; их имена и назначение записаны в [`hostcmsfiles/README.md`](../hostcmsfiles/README.md). Проверить соответствие ID на сервере.
- `hostcmsfiles/documents/manifest.json` перечисляет снимки документов из БД с ID, именем, `template_id` и датой. Эти HTML-файлы не являются файлами публикации на сервер.
- `src/scss/` содержит исходники дизайн-системы; `core/` описан как снимок активного CSS на дату экспорта; `package.json` содержит команды сборки и lint.
- `scripts/export-hostcms-documents.php` и `scripts/sync-hostcms-documents.php` существуют. Их применение описано в [`hostcms-deployment.md`](hostcms-deployment.md); перед запуском требуется ревью кода и окружения.
