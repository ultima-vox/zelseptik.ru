# Карточки каталога и маршрутизация форм — 8 октября 2026

Изменения применены только на dev.zelseptik.ru. Production не изменялся.

## Карточки

Общие сетки каталога получили одинаковые по высоте строки. Карточки растягиваются по высоте, тело занимает свободное место, цена и кнопки выровнены. Убраны лишние горизонтальные отступы тела карточки. Характеристики используют гибкую колонку подписи и колонку значения без переноса: «Производительность: 750 л/сутки» помещается в одну строку. Высота остаётся естественной, без обрезания содержимого.

## Формы

JS подключает обработчик заявки только к явно обозначенным POST-формам заявки, модального окна и CTA с полем телефона. Универсальный data-ajax-form больше не означает отправку письма. Формы с полями фильтрации исключены из обработчика.

PHP принимает заявку только при _zs_action=lead и исключает поля filter, sorting, price_from, price_to, producer_id, on_page и property_*. Остальные запросы остаются у штатных контроллеров HostCMS. Существующие Core_Mail, проверка телефона и reCAPTCHA сохранены. Новые сущности CMS не создавались.

## Проверка

Автоматические проверки PHP-синтаксиса, JS-синтаксиса и маршрутизации форм прошли в GitHub Actions: https://github.com/ultima-vox/zelseptik.ru/actions/runs/37764518954. Тесты используют заглушку почтового транспорта; тестовые письма не отправлялись.

При проверке браузером с шириной 1363 px:

| Страница | Видимых карточек | Высота каждой карточки |
| --- | ---: | ---: |
| /septiki/ | 24 | 662,75 px |
| / | 12 | 662,75 px |
| /septiki/topas/ | 22 | 645,25 px |
| /obsluzhivanie-po-gorodam/ | 13 | 494,5 px |

Высоты совпадают внутри каждого списка. На проверенных страницах нет горизонтального переполнения; видимые строки производительности не переносятся. Мобильный размер браузера в этой проверке не эмулировался.

Штатный фильтр открыл /septiki/?filter=1&property_6_from=4&property_6_to=5&property_10=1&property_3=1 через GET, сократив выдачу до 24 моделей. У форм каталога method=get, отсутствует _zs_action; сообщения обработчика заявок не появлялись. Запрет отправки писем для фильтра и сортировки дополнительно проверен на серверной функции автоматическими тестами.
