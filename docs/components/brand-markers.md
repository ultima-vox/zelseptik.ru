# Ключевые визуальные маркеры

Маркеры создают строгий инженерный характер без декоративного шума. Один
выразительный акцент на секцию обычно достаточен.

## Градиенты

- `--gradient-brand` — брендовые акцентные поверхности.
- `--gradient-eco` — экологические и технологические акценты.
- `--gradient-premium` — текст `.premium-slogan` и редкие premium-акценты.
- `--gradient-deep` — крупные тёмные CTA.
- `--gradient-engineering-cta` — инженерный CTA с мягкой глубиной.
- `--gradient-soft-page` — лёгкая подложка hero, подборщика или featured-блока.

Не применять градиенты к обычным карточкам, таблицам и длинным текстовым
секциям.

## Hero Offer Tag

Отвечает на вопрос «что это за предложение?» перед H1. Содержит короткий
сценарий или категорию, максимум 3-5 слов.

```html
<span class="hero-offer__tag">Подбор септика под участок</span>
```

Не использовать как заголовок, CTA или статус товара.

## Premium Slogan

Статусный микрослоган над H1 либо внутри крупного hero/CTA. Не является
бейджем и не заменяет конкретный оффер.

```html
<span class="premium-slogan">Чистота без компромиссов</span>
```

Основной слоган бренда: «Чистота без компромиссов». Допустимы короткие
контекстные варианты до семи слов. Не использовать в карточках каталога,
FAQ, таблицах и обычных SEO-секциях.
