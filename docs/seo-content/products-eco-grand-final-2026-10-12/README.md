## Перенос

Сверить актуальные формы и свойства, архивировать прежние поля до изменений. SQL-генератор принимает свежий JSON-экспорт целевой базы:

```bash
python tools/seo/generate-product-content-sql.py --content docs/seo-content/products-eco-grand-final-2026-10-12 --export /path/to/fresh-export.json --output /path/to/reviewed-sql
```

Скрипт заканчивается ROLLBACK, проверяет предыдущие поля и идентичность. Свойства не обновляет. Возможные исправления свойств применить отдельно штатными средствами HostCMS после сверки с источниками. UI-типограф нормализует HTML: для точного SQL-отката нужен экспорт реально сохраненных текущих полей. Цены, комплектация, количество и production в этой партии не меняются.
