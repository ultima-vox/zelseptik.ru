## SQL подготовлен 14.10.2026 — не выполнен

`apply-prices-dry-run.sql` содержит 10 точечных обновлений основной цены существующих товаров магазина 1, группы 13. Проверяются ID, магазин, группа, отсутствие удаления, отсутствие родительской модификации, точные имя и путь, прежняя цена. Повышение допускается только для ненулевой цены ниже целевой. Астра 4 (175) и все новые модификации исключены.

`rollback-prices-dry-run.sql` возвращает прежние цены только при совпадении той же идентичности и новой цены. Откат предназначен для этой партии; после последующих изменений цен нельзя запускать его автоматически.

Оба файла заканчиваются ROLLBACK: это проверка, а не выполненное обновление. Для каждого товара ожидается changed_rows = 1; при любом несовпадении партию не фиксировать. Блокировка FOR UPDATE действует до завершения транзакции. До запуска подтвердить таблицу shop_items и перечисленные поля по свежему экспорту dev, движок InnoDB, сделать резервную копию, сверить конфигурации, скидки/специальные цены и актуальность прайса. Исходные значения взяты с публичных страниц 13.10, не из свежего дампа базы. Прямой SQL требует после применения штатной очистки кеша HostCMS и проверки итоговой цены на карточке, в каталоге и корзине.

14.10 повторное открытие официальной страницы прайса через веб-инструмент не удалось; сохранённая сверка от 13.10 не заменяет проверку перед применением. В админке защищённый вход завершился тайм-аутом; запись цен и оставшихся связей не подтверждена. Production не изменялся.
