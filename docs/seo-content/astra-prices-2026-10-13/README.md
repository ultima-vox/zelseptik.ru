Официальная страница https://sbm-group.ru/price ведет на актуальный прайс https://sbm-group.ru/price-test-2026 (действует с 01.09.2026) и PDF https://sbm-group.ru/wp-content/uploads/1-stanczii-yunilos-serii-astra-i-komplektuyushhie-31.08.2026.pdf . Старый прайс от 12.05.2026 не использовать. Приведены РРЦ без выдуманных скидок; на старой странице есть рекламная цена со скидкой, она не подменяет актуальную таблицу РРЦ.

comparison.json сопоставляет 11 текущих базовых карточек dev и РРЦ для самотечного исполнения. Все текущие цены ниже РРЦ. У Астра 4 оба свойства отвода не отмечены; ее автоматически не менять до подтверждения комплектации (147000 С/Т или 151000 ЕМК). Десять других изменений подготовлены, но в CMS не записаны: текущую цену/скидку/специальные цены нужно повторно сверить перед сохранением и архивировать. Не включать применение основной цены ко всем модификациям. Цены равные либо выше РРЦ не снижать.

23 новых исполнения пока по запросу: стоимость ЕМК, насосов и КНС нужно сопоставить с фактической поставкой. Не складывать цены опций для получения вымышленной цены комплекта. Для 372 дополнительно проверить отключение экспорта Яндекс.Маркета. У КНС цена остается по запросу до полного подтверждения комплектации.

Новая актуальная таблица также подтверждает залповый сброс Астра 5 — 250 л вместо существующих 220 л. Для действующих карточек 176–178 проверить версию и исправить штатные свойства при подтверждении актуальной поставки. Не переносить спорные массы/габариты из разных редакций документов. Production не менялся.

## SQL подготовлен 14.10.2026 — не выполнен

`apply-prices-dry-run.sql` содержит 10 точечных обновлений основной цены существующих товаров магазина 1, группы 13. Проверяются ID, магазин, группа, отсутствие удаления, отсутствие родительской модификации, точные имя и путь, прежняя цена. Повышение допускается только для ненулевой цены ниже целевой. Астра 4 (175) и все новые модификации исключены.

`rollback-prices-dry-run.sql` возвращает прежние цены только при совпадении той же идентичности и новой цены. Откат предназначен для этой партии; после последующих изменений цен нельзя запускать его автоматически.

Оба файла заканчиваются ROLLBACK: это проверка, а не выполненное обновление. Для каждого товара ожидается changed_rows = 1; при любом несовпадении партию не фиксировать. Блокировка FOR UPDATE действует до завершения транзакции. До запуска подтвердить таблицу shop_items и перечисленные поля по свежему экспорту dev, движок InnoDB, сделать резервную копию, сверить конфигурации, скидки/специальные цены и актуальность прайса. Исходные значения взяты с публичных страниц 13.10, не из свежего дампа базы. Прямой SQL требует после применения штатной очистки кеша HostCMS и проверки итоговой цены на карточке, в каталоге и корзине.

14.10 повторное открытие официальной страницы прайса через веб-инструмент не удалось; сохранённая сверка от 13.10 не заменяет проверку перед применением. В админке защищённый вход завершился тайм-аутом; запись цен и оставшихся связей не подтверждена. Production не изменялся.

## Применено через HostCMS 14.10.2026

После восстановления авторизованной сессии официальная страница производителя получена напрямую по HTTPS; дата прайса 01.09.2026 и все 10 целевых цен подтверждены. В штатных формах dev перед каждым сохранением прочитаны ID, магазин, путь, прежняя цена и свойства отвода: самотечный включен, принудительный выключен. Специальные цены пусты, распространение основной цены на модификации выключено. Изменена только основная цена каждого из десяти базовых товаров.

`applied-2026-10-14.json` содержит журнал сохранений и проверки: 10/10 цен подтверждены в разметке карточек и видимом каталоге. Три оставшиеся обратные связи 412/413/415 → 182 добавлены через штатное поле Сопутствующие и проверены на публичных страницах. Прежние поля цен архивированы в `docs/archive/astra-prices-before-2026-10-14/`. SQL не выполнялся; файлы dry-run остаются альтернативой для переноса после проверки свежих данных целевой базы. Их прежние значения на текущем dev уже не совпадают.

Астра 4 не изменена; новые исполнения остаются по запросу. Проверка корзины в эту партию не входила. Предыдущие записи о блокировке и неподтверждённом применении относятся к состоянию до восстановления сессии. Цены и данные production не изменялись.

## Астра 4 согласована и обновлена 14.10.2026

Пользователь согласовал базовую Астра 4 как самотечную за 147000 руб. В штатной карточке 175 включено существующее свойство Самотечный и повышена основная цена с 125000 до 147000; принудительное свойство выключено. Карточка dev подтверждает цену 147000 и самотечный отвод. Модификация 373 Астра 4 Пр проверена: принудительное свойство включено, самотечное выключено, цена по запросу. В astra4-applied-2026-10-14.json сохранены прежние значения. Теперь основные цены всех 11 базовых Астра обновлены на dev. Исторические заметки об исключении Астра 4 относятся к состоянию до согласования. Production не изменялся.
