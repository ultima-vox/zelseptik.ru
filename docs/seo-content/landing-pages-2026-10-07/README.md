# Основные посадочные: первый этап SEO-текстов

Тексты сохранены через редактор существующих сущностей HostCMS на **dev** 7 октября 2026. Production не изменялся. Содержимое базы не переносится обычным FTP-деплоем: при переносе кода необходимо отдельно перенести указанные поля через CMS. HTML-файлы в этом каталоге — исходники новых блоков, а не полный экспорт сущностей.

| Страница | Существующая сущность | Поле и действие |
| --- | --- | --- |
| `/` | Документ 6 «Почему выбирают нас» | Добавить `home.html` в конец текущего содержимого, сохранив блок «Что учитываем до начала монтажа» |
| `/septiki/` | Магазин 1 | `description`, содержимое `septiki.html` |
| `/montazh-septika/` | ИС 7 | `description`, содержимое `montage.html` |
| `/obsluzhivanie-septikov/` | ИС 8 | `description`, содержимое `service.html` |
| `/remont-septikov/` | ИС 9 | `description`, содержимое `repair.html` |
| `/obsluzhivanie-po-gorodam/` | Магазин 6 | `description`, содержимое `geography.html` |

Каждый блок содержит H2, два тематических H3 и внутренние ссылки на связанные услуги. Цены, сроки приезда и гарантии не придуманы. Конкретные условия заказа нужно подтверждать отдельно. H1, метаданные, карточки городов и товаров этим этапом не менялись. Ссылка `/services/montazh-septikov/` перенаправляется на `/montazh-septika/montazh-septika-topas/`. Поэтому общий SEO-текст размещён на `/montazh-septika/`. Временное дополнение элемента ИС 3, 158 восстановлено; брендовая страница не менялась.

Вывод нативных описаний: `hostcmsfiles/xsl/55.xsl` для магазинов 1 и 6; `hostcmsfiles/xsl/3.xsl` для ИС 7, 8 и 9. Общий текст исключён из категорий, пагинации, тегов, производителей и SEO-фильтров; у SEO-фильтров остаётся собственный текст. Тексты доступны в серверном HTML без JavaScript. Типографика ограничена атрибутом `data-seo-landing` и использует переменные существующей дизайн-системы.

Проверки: `python3 tests/test-seo-landing-render.py`, `python3 tests/test-service-order-render.py`. Dev-деплой XSL/CSS: `scripts/deploy-dev-seo-landings.py`, фиксированный список файлов, проверка исходных SHA256, зашифрованный бэкап и откат при ошибке записи. Скрипт не меняет базу данных.

## Исправление контекста вывода и UI

При повторной визуальной проверке выявлено, что общий текст магазина 1 и ИС 7 выводился также внутри встроенных каталогов и примеров работ на главной. Теперь общий макет передаёт маркер `landing_description=1` только основному контроллеру страницы, вместе с отдельной сигнатурой кэша. Общие XSL требуют этот маркер для SEO-блоков, а встроенные контроллеры его не получают. Новых сущностей и полей базы не создаётся.

SEO-панели имеют окантовку, скругление и фон существующих панелей услуг; внешние отступы отделяют их от карточек и CTA. Карточки основных посадочных ИС 7/8/9 получают оформление услуг. Контактной колонке футера выделено три колонки сетки вместо двух, номер телефона не переносится. Встроенные карусели и статьи не получают оформление посадочной услуги.

Документация маркера и сигнатуры кэша: https://www.hostcms.ru/documentation/modules/core/controllers/
