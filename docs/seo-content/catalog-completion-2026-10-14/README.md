# Завершение каталога — в работе

Проверены 13 групп магазина 1: 196 базовых карточек и отдельно 23 новые модификации Астра. Не объявлять каталог готовым: предварительная проверка текста выявила 151 базовую карточку без описания с разделами. Технический критерий H3 служит для поиска кандидатов, не оценкой качества всего текста. Повторная проверка всей партии после исправлений обязательна.

На dev через штатные редактируемые поля списка товаров HostCMS повышены 52 основные цены: 22 ТОПАС, 22 ТОПАС-С, 8 ТОПОЛЬ. Источник: официальный прайс ТОПОЛ-ЭКО https://www.topol-eco.ru/prices/ . Пользователь выбрал колонку «Рекомендованная цена МОСКВА»; цены со склада и монтаж не смешиваются с ней. Каждая цена проверена после перезагрузки админки и в публичном каталоге. Прежние поля таблицы архивированы. Другие значения таблицы не редактировались. Production не изменялся.

Восемь ТОПОЛЬ Плюс/Плюс Пр требуют сверки со старым паспортом и текущим Long: автоматического переименования и обновления цены нет.

Для Эко-Гранд пользователь выбрал базовую комплектацию «Доступная»: Hiblow/Secoh с электромагнитным клапаном. В опубликованном заводском Excel также есть Hiblow DUO и классическая с двумя компрессорами. Цена этой партии ещё не применена.

ТОПАС-С: нужно завершить 22 текста и штатные характеристики. У ТОПАС-С 4 обнаружено значение пользователей 3 вместо официальных 4; пока не исправлено.

Остальные бренды и восемь старых базовых Астра также требуют проработки карточек. Остаток общих замечаний Астра: отображение цены по запросу в XSL, изображения/схемы КНС, аудит экспорта 372.
