# Городские посадочные — второй этап

**Статус: опубликовано и проверено на isolated dev 08.10.2026.** Тексты и метаданные сохранены через штатные формы HostCMS; XSL 56 установлен через Actions run 37688667891. Production не менялся.

Используется существующий магазин 6: элементы 240 (Красногорск), 233 (Зеленоград), 236 (Истра), 238 (Химки), 242 (Солнечногорск). Пути и предлагаемые метаданные — в `manifest.json`. Поле `description` сохраняется коротким; новые блоки предназначены для существующего поля `text`. Названия, цены, изображения и дополнительные свойства не менять.

До изменения поле text содержало старые тексты, которые активная часть XSL 56 не выводила. Теперь вывод `text` ограничен магазином 6 и пятью указанными элементами, чтобы не открыть непроверенные старые тексты других городов. Блок использует существующее оформление `data-seo-landing` и доступен в серверном HTML.

Перед публикацией: получить свежий экспорт выбранных записей; сравнить ID, магазин и текущий путь с manifest; сохранить исходные `text`, `seo_title`, `seo_description`; заменить поля через штатную форму HostCMS; после этого переносить изменение XSL. Значения из старого бэкапа не являются основанием для массовой записи.

`tools/seo/generate-city-content-sql.py` создаёт SQL применения и отката только из свежего экспорта выбранных строк. Набор ID и путей фиксирован manifest. UPDATE проверяет старые значения всех изменяемых полей; по умолчанию транзакция заканчивается ROLLBACK. Скрипт не подключается к базе и не выполняет SQL.

Пример подготовки после получения актуального JSON экспорта:

```sh
python3 tools/seo/generate-city-content-sql.py \
  --export /absolute/path/current-shop6-rows.json \
  --output /absolute/path/reviewed-city-content
```

Формат экспорта: массив объектов с `id`, `shop_id`, `path`, `deleted`, `text`, `seo_title`, `seo_description`. NULL сохранять как JSON null. ID и пути берутся из существующих записей, не создавать новые элементы.

Официальная документация:
- https://www.hostcms.ru/documentation/modules/shop/item/add/
- https://www.hostcms.ru/documentation/modules/shop/frontend/show-items/
- https://www.hostcms.ru/documentation/step-by-step/templates/show-shop/

Неподтверждённые цены, сроки выезда, гарантии и особенности грунта отдельных городов в тексты не добавлены. H1 и URL этим этапом не меняются. Остальные городские страницы ещё требуют отдельной подготовки.

## Проверка dev

Все пять URL возвращают 200, один H1 и один новый SEO-блок в серверном HTML. Метаданные соответствуют manifest; все шесть целей контекстных ссылок отвечают 200. Результаты: `verification-live-2026-10-08.json`.

Исходные значения из форм: `docs/archive/seo-city-content-before-2026-10-08/current-fields.json`. У Красногорска HTML считан из окна исходного кода редактора; TinyMCE может нормализовать пробелы, поэтому этот архив предназначен для восстановления через CMS, а не как гарантированно точный бинарный SQL-экспорт. Для production SQL нужен свежий экспорт непосредственно из целевой БД. После записи через CMS работает типографика HostCMS, и сохранённый HTML может отличаться от авторского; не выполнять бинарно защищённый SQL отката без проверки фактических значений.
