# ТОПАС: SEO карточек — 08.10.2026

На изолированном dev через существующий магазин HostCMS `shop_id=1`, группу
`shop_group_id=10` обновлены 22 существующих товара. Новые магазины, свойства,
дубли страниц и URL не создавались. Заполнены нативные `description`,
`seo_title`, `seo_description`; ошибочные ключевые слова другой модели удалены.

Тексты помогают выбрать исполнение по глубине трубы и отводу воды. Включают
ссылки на альтернативные модели, категорию (кроме индивидуального текста
ТОПАС 10 Лонг), монтаж, доставку и сервис. Используется существующее оформление
описания карточки. Общие рекомендации не заменяют паспорт и обследование участка.

## Проверка

`verification-live.json`: проверены все 22 публичные карточки — уникальные
title, точные description, один H1, текст, производительность, залповый сброс,
отвод и горловина. На dev сохранен noindex. Штатное перестроение быстрого фильтра
завершено; Long + Принудительный дает ровно 5 соответствующих моделей.
Все связанные модели открыты в этой проверке, целевые страницы доставки,
монтажа и обслуживания также проверены. Визуально проверено описание ТОПАС 10 Лонг.

## Перенос

Эти изменения находятся в базе HostCMS, одного обновления CSS/XSL недостаточно.
Предпочтителен согласованный перенос финальных данных dev после завершения работ.
Исходные значения форм сохранены в `docs/archive/products-topas-before-2026-10-08/`.
Это журнал изменений, **не свежий экспорт целевой БД**.

Для выборочного переноса только SEO подготовлен
`tools/seo/generate-product-content-sql.py`. Он требует свежий JSON-экспорт
ровно этих 22 записей `shop_items` из целевой базы со столбцами:
`id, shop_id, shop_group_id, path, deleted, description, seo_title,
seo_description, seo_keywords`. Проверяет идентичность товаров, защищает UPDATE
сравнением всех исходных полей, генерирует обратный SQL. Оба скрипта по умолчанию
завершаются ROLLBACK и никогда не подключаются к базе.

```sh
python3 tools/seo/generate-product-content-sql.py \
  --export /path/to/fresh-products.json --output /path/to/reviewed-sql
```

SQL переносит тексты и метаданные. Исправления свойств из таблицы и признака Long
нужно перенести отдельно штатными средствами HostCMS, затем перестроить фильтр.
На prod ничего не применено. Остальные 174 товара этого магазина этим пакетом
не оптимизированы. Следующий этап: ТОПАС-С, Юнилос Астра и остальные бренды,
далее технический аудит canonical, sitemap, индексации и структурированных данных.
