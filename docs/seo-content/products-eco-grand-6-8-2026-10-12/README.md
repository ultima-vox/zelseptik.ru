## Публикация

Используются description, seo_title, seo_description, seo_keywords существующих товаров HostCMS. Официальная документация: https://www.hostcms.ru/documentation/modules/shop/item/add/ . Новые магазины, ИС или страницы не создаются; HTML без inline-стилей.

1. Сверить идентичность и users/capacity/burst/drainage по свежим формам dev и конкретной версии станции.
2. Сохранить прежние поля перед редактированием. Существующие свойства менять только после отдельной проверки расхождения.
3. Внести description/SEO через штатный интерфейс либо сформировать SQL из свежего экспорта целевой базы:

```bash
python tools/seo/generate-product-content-sql.py --content docs/seo-content/products-eco-grand-6-8-2026-10-12 --export /path/to/fresh-export.json --output /path/to/reviewed-sql
```

4. Проверить сохраненные поля, видимый текст, title/description, H1, внутренние ссылки, дизайн и мобильную версию. До этого status остается prepared_not_published.

SQL по умолчанию заканчивается ROLLBACK, содержит защиту по текущим полям и идентичности; цены/свойства не меняет. При UI-сохранении типограф может нормализовать HTML: для точного SQL-отката нужен экспорт фактически сохраненных текущих полей, а не исходный HTML.
