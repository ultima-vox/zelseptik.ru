## Перенос и откат

Официальные поля HostCMS: description, seo_title, seo_description, seo_keywords. Документация: https://www.hostcms.ru/documentation/modules/shop/item/add/ . HTML без inline-стилей. При переносе нужен свежий экспорт и резервная копия конкретной целевой базы:

```bash
python tools/seo/generate-product-content-sql.py --content docs/seo-content/products-eco-grand-6-8-2026-10-12 --export /path/to/fresh-export.json --output /path/to/reviewed-sql
```

SQL заканчивается ROLLBACK и проверяет прежние текстовые поля/ID/магазин/группу/путь. Свойства и цены генератор не обновляет. Исправление свойства 270 при переносе необходимо отдельно сверить и применить штатными средствами HostCMS; оно отражено в manifest.json и verification-live.json. Для UI-отката вернуть прежние поля из резервной копии, включая свойство 4 товара 270 при необходимости.

Типограф формы нормализует пробелы/тире. Для точного SQL-отката после UI-публикации экспортировать реально сохраненные текущие поля: исходный HTML не является точным значением для защитного WHERE.
