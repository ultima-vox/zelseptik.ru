Официальная документация HostCMS:
- https://www.hostcms.ru/documentation/modules/shop/item/add/

Статус публикации и результаты проверки указаны в manifest.json и verification-live.json. Изменения предназначены для isolated dev; production не изменяется. Для переноса данных на production необходим свежий экспорт целевых записей и сравнение их ID/путей/значений. HostCMS типографирует HTML при сохранении; авторский HTML не является бинарным снимком БД.
