## Публикация средствами существующего HostCMS

Использовать существующие товары магазина: основное описание и штатные поля SEO. Официальная документация: https://www.hostcms.ru/documentation/modules/shop/item/add/ . Дополнительные страницы, инфосистемы, магазины и шаблоны не создаются. HTML без inline-стилей, только абзацы, заголовки h3 и ссылки; действующий шаблон карточки уже оформляет описание.

Для будущего переноса через SQL на другую целевую базу:

1. Получить актуальные записи shop_items для трех ID: id, shop_id, shop_group_id, path, deleted, description, seo_title, seo_description, seo_keywords; сохранить резервную копию.
2. Сверить фактическую версию станций и существующие свойства с verified_facts. Генератор обновляет только тексты, не свойства, цены или фильтры.
3. Проверить целевые URL карточек, категории, монтажа, доставки и обслуживания. URL составлены по существующим путям проекта, но не помечены как проверенные на dev.
4. Сгенерировать защищенные SQL apply/rollback из свежего JSON-экспорта:

```bash
python tools/seo/generate-product-content-sql.py --content docs/seo-content/products-eco-grand-2026-10-11 --export /path/to/fresh-export.json --output /path/to/reviewed-sql
```

Оба файла заканчиваются ROLLBACK. Каждый UPDATE защищен ID/магазином/группой/путем и предыдущими текстами. Ожидается changed_rows=1 для каждой карточки; при любом расхождении откатить и сверить данные. После согласованного применения проверить видимое описание, title/description, ссылки и мобильный вид на dev; зафиксировать результаты отдельно. Не выдавать подготовку файлов за публикацию.
