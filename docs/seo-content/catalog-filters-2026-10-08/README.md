# SEO-подборки каталога — 8 октября 2026

На изолированном dev обновлены существующие SEO-фильтры магазина 1 (ID 1–11): для дома и дачи, на 4/6/9/10/12 пользователей, самотечный и принудительный отвод, Long и Midi. Новые сущности не создавались; условия фильтров, URL, активность и индексирование сохранены.

Поля seo_title, seo_description, h1 и text редактировались штатным интерфейсом HostCMS. У ID 10 название «Высокий УГВ» заменено на Long: условие фильтра — Long, а пригодность для грунтовых вод нельзя выводить из названия исполнения. Тексты не содержат неподтверждённых скидок, паспортных чисел или гарантий для любых грунтов.

XSL 55 выводит нативный /shop/shop_filter_seo/text один раз на первой странице подборки в существующих section/area-text/legal-page__content. H1 использует существующий вывод поля h1. Произвольные комбинации фильтра не получают текст без совпавшего SEO-фильтра. CSS не менялся.

Официальная документация интеграции: https://www.hostcms.ru/documentation/modules/shop/seo-filter/ — поля SEO-фильтра и XML text/h1.

Исходные поля и XSL сохранены в docs/archive/seo-filters-before-2026-10-08/. Проверка отрисовки: python3 tests/test-filter-seo-render.py; проверка остальных посадочных: python3 tests/test-seo-landing-render.py. Результат проверки dev сохранён в verification-live.json.

Для переноса на production нужны актуальный экспорт соответствующих строк shop_filter_seos и резервная копия целевой базы перед миграцией. Архив интерфейса — история изменений, не замена свежему экспорту целевой БД. Категорийный SQL-генератор из предыдущего этапа не обновляет SEO-фильтры; миграцию фильтров следует добавить в общий пакет перед переносом. Production в этом этапе не изменялся.

Отдельно остаётся аудит карточек товаров и их характеристик по паспортам производителей: тексты подборок не исправляют неточности товарных данных.
