# Материалы до сверки с продакшеном

`repository-before-sync/` сохраняет исходные файлы коммита,
указанного в `manifest.json`, без изменения содержимого. `.editorconfig` сохранён
в корне; его исходная контрольная сумма также записана в манифесте.

Архив включает:

- прежние `core/`, SCSS, JS и заготовку `dist/`;
- варианты `design system/`;
- старую документацию и UI-kit;
- прежний package.json и настройки инструментария.

Причины: отсутствие подтверждённого соответствия сборки CSS действующему сайту,
заглушки в JS и SCSS, несколько параллельных описаний компонентов, устаревшие
инструкции подключения. Например, старые calculator.js и catalog.js не реализуют
действующие модули сайта, а README описывает отсутствующую JS-сборку.

Не все архивные решения признаны ошибочными или устаревшими: полезные идеи
сохранены как исторические материалы. Архив не является источником текущих
инструкций и не должен автоматически попадать в сборку или деплой.
