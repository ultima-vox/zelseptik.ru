01. Цветовая система (Color Palette)

Использование фиксированных токенов цвета из tokens.css. Случайные оттенки запрещены.

Primary --color-primary #23a455
Primary Hover --color-primary-hover #1c8a45
Primary Soft --color-primary-soft #eaf6ee
Text Main --color-text-main #1a1f26
Text Muted --color-text-muted #626c7a
Background --color-bg-page #f8fafc
Surface --color-surface #ffffff
Border --color-border #e2e8f0

ПРАВИЛА ПРИМЕНЕНИЯ (DO)

  • Зеленый Primary — только для кнопок действия, цен и активных состояний фильтров.
  • Фон Surface используется для обособления контентных плит (карточки, калькулятор) на общем фоне страницы.

ЗАПРЕТЫ (DON'T)

  • Запрещено красить плашки в оранжевый или любые другие цвета, отсутствующие в схеме ядра.
  • Запрещено использовать чистый черный (#000) для текстов параграфов.

03. Premium Slogan System

Фирменный стилеобразующий элемент верхнего уровня, отражающий бескомпромиссный инженерный характер бренда на dev.zelseptik.ru.

«Чистота без компромиссов»

Автономные очистные сооружения Топас

ПРАВИЛА ИСПОЛЬЗОВАНИЯ (DO)

  • Размещать исключительно над заголовками H1 в секции Hero или в крупных сквозных блоках CTA.
  • Текст лозунга должен быть коротким и емким (строго от 2 до 4 слов).
  • Словоформа обязана содержать канонические кавычки-ёлочки.

КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО (DON'T)

  • Запрещено интегрировать компонент внутрь карточек товаров или списков каталога.
  • Запрещено использовать класс в главных или второстепенных меню навигации.
  • Запрещено применять стилистику для длинных информационных предложений.
HTML-разметка компонента .premium-slogan
<div class="premium-slogan">«Чистота без компромиссов»</div>

09. Custom.css Governance

Регламент расширения кодовой базы. Защита системного ядра от несанкционированных мутаций стилей.

РАЗРЕШЕНО ДОБАВЛЯТЬ В CUSTOM.CSS

Специфичные стили для временных маркетинговых баннеров акций, уникальные точечные css-анимации появления блоков, микронастройки внешних отступов (margin-bottom) для конкретных посадочных страниц.

КАТЕГОРИЧЕСКИ ТАБУИРОВАНО

Запрещено переопределять базовые токены цвета, размеров и радиусов. Запрещено использовать инлайн-стили style="" в разметке страниц. Запрещено использовать префикс документации ds-* в коде боевого сайта.
