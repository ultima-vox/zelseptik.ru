# ЗЕЛСЕПТИК — рабочие исходники сайта

Основа синхронизирована с действующим zelseptik.ru и бекапом от 05.10.2026.
CSS на действующем сайте имеет приоритет над историческими исходниками.

## Рабочие файлы

| Путь | Назначение |
| --- | --- |
| `assets/css/app.min.css` | Подключённая на сайте сборка CSS, сохранена без изменений |
| `assets/css/runtime.min.css` | Подключённый на сайте слой переопределений |
| `assets/css/core/` | Доступные на сайте отдельные CSS; не считать их доказанным источником сборки app.min.css |
| `assets/js/` | Действующая точка входа и модули JS |
| `templates/template*/` | Макеты HostCMS и их CSS/JS из бекапа; подключённые на эталонных страницах CSS/JS дополнительно сверены с сайтом |
| `hostcmsfiles/xsl/` | XSL, найденные по статическим вызовам и параметрам структуры, с зависимостями |
| `hostcmsfiles/lib/` | Типовые динамические страницы, привязанные к структуре сайта |
| `hostcms/documents/` | HTML существующих документов, экспортированный из `documents.text` |
| `hostcms/inventory.json` | ID и связи существующих сущностей CMS |
| `docs/` | Актуальные правила, результаты сверки и план унификации UI |
| `archive/2026-10-05/` | Неизменённые материалы репозитория до сверки |

## Проверка

Требуется Python 3; внешние библиотеки не нужны.

```bash
python3 scripts/verify-baseline.py
```

На Windows можно использовать `py -3 scripts/verify-baseline.py`.
Проверка сверяет контрольные суммы рабочего снимка и архива, относительные импорты JS и зависимости XSL.

## Статус сборки и внедрения

Прежняя SCSS-сборка не подтверждена как источник действующего CSS, поэтому её код,
package.json и документация сохранены в архиве. Не запускать старую сборку для замены
рабочего app.min.css. Воссоздание воспроизводимой сборки — отдельная задача.

Это рабочий экспорт для доработок, а не полный дистрибутив сайта: ядро CMS, база,
загрузки и конфигурация окружения в репозиторий не включены. Экспорт не выкладывать
целиком на сервер автоматически. Документы переносить в существующие записи по ID;
файлы `hostcms/documents/` сами по себе не являются штатным расположением документов CMS.
