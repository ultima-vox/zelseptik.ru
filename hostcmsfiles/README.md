# HostCMS source snapshot

Эта директория хранит редактируемую копию серверного слоя сайта.

## Состав

- `xsl/` — XSL, прямо вызываемые активными шаблонами HostCMS.
- `documents/` — HTML текущих документов сайта `site_id = 1`.
- `documents/manifest.json` — ID, имя, шаблон и дата документа на момент экспорта.

HTML-документы нельзя загружать в файловую систему сайта: в HostCMS они живут в БД.
Их обновление выполняется отдельным контролируемым импортом с резервной копией строк БД.

XSL загружаются в `/hostcmsfiles/xsl/` с сохранением ID файла. Имя и ID XSL
сверяются через HostCMS перед деплоем.
